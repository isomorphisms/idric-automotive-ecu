# TriCore TC1.8 reference

This branch is architecture reference material, not an executable Idriç backend.

Document the current TC1.8 architecture, ABI, register model, instruction families, object/relocation conventions, and public tooling status. Keep older TriCore generations distinct from current TC1.8.

## Promotion gate

Move this target under `follower/` only after a clean machine can reproducibly:

1. assemble and link a TC1.8 program,
2. execute it with publicly obtainable tooling or an accessible hardware path,
3. observe a deterministic result, and
4. repeat the same loop for compiler-generated bytes.

Until then, do research and inventory work only.

Tracked by issue #5.
